## Tracking

- [ ] **Debt 1 — a shared `runAsEntrypoint(meta, argv, fn)`, tested once, plus the guard test that makes
      it stick.**
  - [ ] Every top-level `scripts/*.mjs` ends with an `isEntrypoint(import.meta.url, process.argv[1])`
        block **no test can import**. Files whose whole body is that shape score **0 %**:
        `upstream-check-run.mjs` (new in v4.8.0 — it fell into the shape the same week the shape was
        named) and `session-status.mjs` (**inherited**, named as debt since v4.4.0 and carried by every
        published tag since). `status-line.mjs` is the third known one.
  - [x] **20 files carry the shape.** Measured at v4.8.0, not estimated — re-count before starting, then
        write the number down here. **RE-COUNTED 2026-08-15, and the number grew: 28 of the 32
        non-test `scripts/*.mjs` carry an entry guard**, in **two different spellings** — 16 through the
        shared `isEntrypoint()` predicate, 12 through a hand-rolled `import.meta.url` / `argv[1]`
        comparison or no guard at all. **9 have no `.test.mjs` sibling**: `import-brain`, `open-env`,
        `pick-folder`, `run-eval`, `session-status`, `status-line`, `update-engine`,
        `upstream-check-run`, `verify-rag`. That list is the guard test's starting allowlist, and it may
        only shrink.
  - [x] **The predicate is NOT the debt — measured 2026-08-15.** `scripts/lib/entrypoint.mjs` is already
        shared and tested. The debt is one level up: the **body inside the guard cannot be imported**, so
        nothing reaches it. And the two named 0 % files are worse than guarded — `session-status.mjs` and
        `status-line.mjs` carry **no guard at all**, their whole body runs on import, which is why no test
        can even load them without side effects. The helper must therefore take **the body as a
        function**, not merely answer "am I the entry point?".
  - [ ] The design was settled at v4.5.0 and is not to be re-opened: **one** shared helper, tested once,
        with the per-script body passed in as a function.
  - [ ] **The guard test is the half that makes it stick** (without it, the next new script re-creates
        the debt): a harness-suite test that goes **red** when a top-level `scripts/*.mjs` has no
        `.test.mjs` sibling, **and** when a module builds and executes a child process in the same
        function. It carries an **allowlist that may only SHRINK** — a list that can grow is a list that
        will.
  - [ ] Re-measure the touched files afterwards and record the numbers in `RESULTS.md` (a
        hardened-but-unmeasured file has an unknown score).
- [ ] **Debt 2 — `defaultGit` turned into a pure value.**
  - [ ] `scripts/lib/engine-fetch.mjs:104-109` is the real git runner and **21 mutants live in it**
        (the file scores **54.05 %**, its lowest-scoring neighbour by a wide margin).
  - [ ] **The identical shape was solved once already**, at v4.5.0 in `verify-index.mjs`: the spawn's
        request became a **pure value** (`buildCrosscheckInvocation` → `{command, args, options}`,
        asserted whole, `win32` fed on purpose), which killed 19 survivors. It was **never propagated**.
        Mirror it rather than invent a second shape.
  - [ ] The code currently **documents its own exemption** — *"Used by the core's CLI wiring, never by
        the unit tests"* — which is exactly what reflex 6 of the **`test-first-discipline`** skill
        forbids (*"pure glue, not testable" is never an excuse — it is the diagnosis*). Delete that
        comment with the fix. _(Skill renamed from `tdd-discipline` on 2026-08-15; the reflex is
        unchanged and was kept verbatim.)_
  - [ ] Re-measure `engine-fetch.mjs` and record the number.
- [ ] **Explicitly NOT in scope, and not to be re-proposed** _(owner, 2026-08-05)_: an **11th written
